# aaronudho.com

Flat files. No folders, no build step. Upload everything to the root of the repo.

```
index.html     the whole site
CNAME          points GitHub Pages at aaronudho.com, don't delete
product-1.jpg  digital product covers
product-2.jpg
photo-1.jpg    photos of you
```

## Adding a digital product cover

Upload an image named `product-3.jpg`, then `product-4.jpg`, and so on.
It appears in the rotating cover shelf automatically. Nothing to edit.

## Adding a photo of yourself

Upload an image named `photo-2.jpg`, then `photo-3.jpg`, and so on.
The arrows under the photo step through them.

## The one rule

**Numbers must run 1, 2, 3 with no gaps.** The page tries each number in order and stops at the
first one missing, so if you have 1, 2 and 4, the 4 never shows. `.jpg`, `.jpeg`, `.png` and
`.webp` all work. Keep covers portrait and photos square, under about 300KB each.

## Email

`info@aaronudho.com` runs on iCloud+ Custom Email Domain. Sends and receives in Apple Mail.

## Previewing before you upload

Unzip the whole folder and open `index.html` from inside it.
